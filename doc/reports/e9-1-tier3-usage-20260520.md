## What this report does NOT do

- Does not look at logs older than 30 days. If a tenant ran tier-3 traffic 60+ days ago and stopped, this report won't see them. Mitigation: deprecation 90-day window covers re-entrants.
- Does not check 2c-svc-lucrum / 2c-bs-forge / other Lurus services for tier-3 dependencies. Their codepaths may import lurus-newhub tier-3 endpoints. Cross-service grep is a follow-up task before E9-3 code removal.
- Does not check `newapi.lurus.cn` from an external client perspective (e.g. is anyone curling `/v1/images/generations` and getting 404s?). All metrics are server-side `logs` table reads.

## Known issues

- **`scripts/story-9-1-tier3-audit-drill.sh` has a default-db bug**: hardcoded escape `\${POSTGRES_DB:-lurus_hub}` reads remote shell env, not local. Local `export POSTGRES_DB=newhub` does not propagate. Mitigation: bypassed wrapper this run; will be fixed in a follow-up patch so future runs are one-command.
- **DB name discrepancy**: R6 STAGE uses db=`newhub`, R1 PROD uses db=`newapi`. The wrapper needs a `--db <name>` flag (or two transports) before it can do both in one invocation.
